建议按三个可验收增量开发：

1. **事实与任务底座**：只读资金调查 API、可信关联、任务持久化、独立 Agent 运行时。
2. **客服双向协作**：客服发起/查询调查，调查请求补充资料，结果跨会话送达，人工可接管。
3. **运营闭环**：对账差异主动建案、财务审核、受控补确认、执行后复查。第一版不开放 Agent 自动发起退款。

核心边界：Agent 整理和调查异常；金额核算、事实确认、资金操作仍归现有业务服务。订单已退款、平台已出账、渠道退款成功、买家到账是不同事实，不能合并成一句“钱已经退回”。
